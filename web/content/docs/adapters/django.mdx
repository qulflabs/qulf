# Django ORM Adapter

`DjangoORMAdapter` implements both `DatabaseAdapter` and `SchemaAdapter`. It uses Django's native async ORM methods (`acreate`, `afirst`, `asave`, `adelete`) and falls back to `sync_to_async` for queryset evaluation.

## Basic Setup

There are two approaches depending on whether you use Qulf's built-in models or eject your own.

### Using Default Models

Add Qulf to `INSTALLED_APPS` so Django discovers and migrates the built-in models:

```python title="settings.py"
INSTALLED_APPS = [
    ...
    "qulf.apps.QulfConfig",  # or just "qulf"
    ...
]
```

```python title="myapp/auth.py"
from qulf import Qulf, QulfConfig
from qulf.adapters.django import DjangoORMAdapter

auth = Qulf(
    db=DjangoORMAdapter(),
    config=QulfConfig(secret_key="your-32-char-secret-key-here!!!"),
)
```

```bash
python manage.py makemigrations qulf
python manage.py migrate
```

### Using Ejected Models

Run `qulf init` and choose to eject when prompted. This generates a `models.py` inside your own app, no need to add `"qulf"` to `INSTALLED_APPS`:

```bash
qulf init
# Select: django
# Eject? Yes (recommended)
# Save models to: myapp/models.py
```

The generated file imports Qulf's mixins and registers the models under your app's label:

```python title="myapp/models.py"
# Generated by: qulf init
from typing import Any
from django.db import models
from qulf.adapters.django import UserMixin, SessionMixin, AccountMixin, ...

class User(UserMixin):
    id: Any = models.BigAutoField(primary_key=True)
    class Meta:
        db_table = "user"

# Session, Account, Role, Permission, UserRole, RolePermission, Passkey ...
```

Then pass the models to the adapter and run your app's migrations:

```python title="myapp/auth.py"
from qulf import Qulf, QulfConfig
from qulf.adapters.django import DjangoORMAdapter
from myapp import models

auth = Qulf(
    db=DjangoORMAdapter(
        user_model=models.User,
        session_model=models.Session,
        account_model=models.Account,
        role_model=models.Role,
        permission_model=models.Permission,
        user_role_model=models.UserRole,
        role_permission_model=models.RolePermission,
        passkey_model=models.Passkey,
    ),
    config=QulfConfig(secret_key="your-32-char-secret-key-here!!!"),
)
```

```bash
python manage.py makemigrations myapp
python manage.py migrate
```

Ejecting is recommended because it lets you freely extend models, customize table names, and add app-specific fields without touching Qulf internals.

## Custom Models

Inherit from the provided abstract mixins and pass your models to the adapter constructor:

```python title="myapp/models.py"
from typing import Any
from django.db import models
from qulf.adapters.django import UserMixin, SessionMixin, AccountMixin, RoleMixin, PermissionMixin, PasskeyMixin

class User(UserMixin):
    id: Any = models.BigAutoField(primary_key=True)
    stripe_customer_id = models.CharField(max_length=255, null=True, blank=True)

    class Meta:
        db_table = "users"

class Session(SessionMixin):
    id: Any = models.BigAutoField(primary_key=True)
    user: Any = models.ForeignKey(User, on_delete=models.CASCADE, related_name="sessions")

    class Meta:
        db_table = "sessions"

# Define Account, Role, Permission, UserRole, RolePermission, Passkey similarly...
```

```python title="myapp/auth.py"
from qulf.adapters.django import DjangoORMAdapter
from myapp import models

adapter = DjangoORMAdapter(
    user_model=models.User,
    session_model=models.Session,
    account_model=models.Account,
    role_model=models.Role,
    permission_model=models.Permission,
    user_role_model=models.UserRole,
    role_permission_model=models.RolePermission,
    passkey_model=models.Passkey,
)
```

## Available Mixins

| Mixin | Key Fields |
|---|---|
| `UserMixin` | `email`, `name`, `username`, `hashed_password`, `created_at`, `updated_at`, `deleted_at`, `email_verified_at` |
| `SessionMixin` | `token`, `expires_at`, `ip_address`, `user_agent`, `created_at` |
| `AccountMixin` | `provider_id`, `account_id`, `access_token`, `refresh_token`, `expires_at`, `scope`, `id_token` |
| `RoleMixin` | `name`, `description`, `created_at` |
| `PermissionMixin` | `name`, `description`, `created_at` |
| `PasskeyMixin` | `credential_id`, `public_key`, `sign_count`, `name`, `created_at` |

## Default Models

When using `DjangoORMAdapter()` with no arguments, these concrete models are used (registered under the `qulf` app label):

| Model | Table |
|---|---|
| `DefaultUser` | `user` |
| `DefaultSession` | `session` |
| `DefaultAccount` | `account` |
| `DefaultRole` | `role` |
| `DefaultPermission` | `permission` |
| `DefaultUserRole` | `user_role` |
| `DefaultRolePermission` | `role_permission` |
| `DefaultPasskey` | `passkey` |

## Plugin Schema Injection

`DjangoORMAdapter` implements `SchemaAdapter.inject_custom_columns()`. When plugins declare custom columns via `get_custom_columns()`, Qulf maps Python types to Django fields and calls `field.contribute_to_class()` at startup:

| Python type | Django field |
|---|---|
| `str` | `CharField(max_length=255, null=True)` |
| `int` | `IntegerField(null=True)` |
| `bool` | `BooleanField(default=False)` |
| `datetime` | `DateTimeField(null=True)` |
| anything else | `JSONField(null=True)` |

Plugins can also provide native Django `Field` instances directly via `get_django_columns()`, these bypass the type mapping entirely. Existing fields are never overwritten.

> To persist plugin columns as real migrations, run `qulf sync` then `python manage.py makemigrations`.

## Using with Non-Django Frameworks (e.g. FastAPI)

You can pair `DjangoORMAdapter` with FastAPI or any other ASGI framework. Django must be initialized before the ORM is touched:

```python title="main.py"
import os
import django

os.environ.setdefault("DJANGO_SETTINGS_MODULE", "myproject.settings")
django.setup()

from qulf import Qulf, QulfConfig
from qulf.adapters.django import DjangoORMAdapter
from qulf.frameworks.fastapi import serve_qulf
from fastapi import FastAPI

auth = Qulf(db=DjangoORMAdapter(), config=QulfConfig(secret_key="..."))
app = FastAPI()
app.include_router(serve_qulf(auth), prefix="/api/auth")
```
